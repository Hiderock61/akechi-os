# 明智君OS v0.5｜現在地一行接続

## 追加したもの

- モード画面に任意入力「いま何が起きてる？」を追加
- 入力内容を、設計・施工・監査・GitHub修理の4種類の問いへ自動挿入
- 空欄ならv0.4.2と同じ問いを使用
- モードを開くたび入力欄は空になる

## 追加していないもの

- 保存
- 履歴
- タスク管理
- ログイン
- 通知
- 自動モード判定

## GitHubへ上げるファイル

- index.html
- script.js
- current-location.css

既存の style.css と visibility.css はそのまま残してください。
